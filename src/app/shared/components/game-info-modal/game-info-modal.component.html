GAME RULES

ABOUT THE GAME

Russian Roulette is a fast-paced game with 1–6 revolver drums. Before the spin you choose how many bullets will be in each drum (1–5) and how many drums participate (1–6). The drums spin and stop under the pointer. If a bullet lands on any drum, the round is lost. If all drums stop on empty chambers, you win. Potential maximum multipliers depend on the selected risk: more bullets and more drums mean higher possible payouts.
